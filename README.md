# B站动态分页浏览 · Bilibili Dynamic Pager

B站用户空间（`space.bilibili.com/<uid>/dynamic`）的**动态分页浏览**用户脚本：
把 B 站“没有页码、只能无限下拉”的动态流改造成**按页浏览**，并补上 B 站没有的**按日期直达 / 直达最早**，方便考古。

由 @UIM258 开发，MIT 协议。

## 功能

- **本地分页**：上一页 / 下一页（末页自动续载）/ 输入页码跳转
- **考古直达**：按日期直达（自动游标扫描定位到某天附近）+ 直达最早（扫描到底）
- **全格式支持**：图文/收藏集、视频/小视频、专栏、纯文字、转发（内嵌原博视频/图片/专栏）、直播预约等附加卡片（投票/抽奖/通用卡片已预留）
- **富文本表情**：收藏集/装扮表情包正确渲染为图片
- **装扮徽章**：显示作者装扮
- **图片灯箱**：点击大图预览，多图 ←/→ 切换
- **直达动态**：每条卡片直达原动态页；也支持输入动态ID直达
- 外观：跟随系统 / 日间 / 夜间
- 接口：`space` 动态接口游标(offset)翻页，脚本本地缓冲后分页

## 安装

1. 安装 Tampermonkey 后打开 `bilibili-dynamic-pager.user.js` 的 Raw 地址即可安装（GreasyFork 搜索“B站动态分页浏览”亦可）
2. 登录 B 站，打开目标用户空间：`https://space.bilibili.com/<uid>/dynamic`
3. 右下角粉色「动态分页」按钮

> 说明：部分 UP 主动态需登录后才能读取（未登录接口可能返回空）。
